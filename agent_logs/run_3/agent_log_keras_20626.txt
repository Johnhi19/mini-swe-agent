    60  
    61  In the layer initialization code, when pre-computed statistics are supplied, the layer calculates two separate tracking shapes:
    62

    64  
    65      _broadcast_shape: The target layout containing singletons for reduced axes (in this case, (3, 1, 5)).
    66

    68  
    69  The codebase relied on flattening/restructuring via explicit dimension mappings:
    70  Python
    71  ```
    72  mean = ops.reshape(mean, self._broadcast_shape)
    73  ```
    74  
    75  Reshaping 15 elements from a (3, 5) matrix into a (3, 1, 5) structure is perfectly valid, allowing the layer to seamlessly inject the missing singleton dimensions.

    76  After PR (The Regression):
    77  
    78  To catch the scalar edge case, the code was refactored to use broadcasting:
    79  Python
    80  ```
    81  mean = ops.broadcast_to(mean, self._broadcast_shape)
    82  ```
