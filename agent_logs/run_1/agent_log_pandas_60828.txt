BUG: `pprint_thing` omits native literal braces for `frozenset` objects (renders `frozenset(1, 2)` instead of `frozenset({1, 2})`)

Pandas Version Context
Affects development branches modifying `pandas.io.formats.printing._pprint_seq` to support native formatting for set-like structures.

Description
When pretty-printing containers that include a `frozenset` via `pandas.io.formats.printing.pprint_thing`, the output drops the internal set boundaries completely. Instead of mirroring Python’s native structural 
layout—which includes internal curly braces inside the parenthesis bounds (e.g., `frozenset({1, 2})`)—it formats the sequence incorrectly as `frozenset(1, 2)`.

This bug happens because literal curly braces inside the underlying `str.format()` template token strings are not escaped. Instead of rendering as raw characters, the formatting engine consumes them as structural 
replacement targets.
